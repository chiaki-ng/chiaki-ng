# chiaki-ng — 32-bit Windows port (work in progress)

This repository is a community fork exploring whether chiaki-ng can be built for **32-bit (x86) Windows** devices. It is based on the upstream [chiaki-ng](https://chiaki-ng.github.io/chiaki-ng/) PlayStation Remote Play project.

> **Status:** 32-bit Windows GUI support is not available yet. The current GUI depends on Qt 6, and this fork has not yet completed or validated a 32-bit-compatible Qt and dependency port. Do not treat this repository or its builds as a working 32-bit release until a successful x86 build and runtime test are published.

See [WINDOWS-32BIT-PORT.md](WINDOWS-32BIT-PORT.md) for the current port scope and verification checklist.

## Downloads

Until this fork publishes a verified 32-bit Windows release, do not assume upstream downloads support 32-bit Windows. When available, fork builds will be published on [this repository's Releases page](https://github.com/vcs-ytg/chiaki-ng-32-bit/releases).

For upstream project documentation, community support, and downloads for officially supported platforms, visit the [chiaki-ng project site](https://chiaki-ng.github.io/chiaki-ng/) and [upstream releases](https://github.com/chiaki-ng/chiaki-ng/releases). This fork is community-maintained and is not an official chiaki-ng release channel.

## Upstream project

chiaki-ng is an open-source PlayStation 4 and PlayStation 5 Remote Play client, continuing the original Chiaki project's work. See the upstream site for platform details, documentation, and the community Discord.
