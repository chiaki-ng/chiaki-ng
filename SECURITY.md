# Security Policy

## Supported Versions

This fork is exploring a 32-bit Windows port. Until this repository publishes a release and identifies a supported version here, **there are no supported 32-bit Windows releases**. The upstream chiaki-ng security policy and releases apply to upstream builds, not automatically to this fork's changes.

## Reporting a Vulnerability

Please do not report security issues in public issues, discussions, or Discord.

For vulnerabilities affecting this fork, report them privately through [this repository's GitHub Security Advisories](https://github.com/vcs-ytg/chiaki-ng-32-bit/security/advisories/new). Include the affected commit or version, steps or input that trigger the issue, and the observed impact. A suggested fix is welcome.

For vulnerabilities affecting upstream chiaki-ng, use the [upstream security reporting page](https://github.com/chiaki-ng/chiaki-ng/security).

We will respond through the private advisory and coordinate disclosure after an appropriate fix is available. Reporters are credited unless they ask not to be.
